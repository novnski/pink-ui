# Security policy

## Supported versions

pink-ui has no releases yet. Fixes land on `main`, which is also what the
[showcase site](https://novnski.github.io/pink-ui/) runs.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's security advisories](https://github.com/novnski/pink-ui/security/advisories/new),
with the affected component or file and the steps to reproduce it.

## Scope

- The library (`src/`) and the web player (`web/`).
- The showcase site (`site/`). It is static: no backend, no accounts, and the
  components run in the browser's sandbox.
